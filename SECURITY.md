# Security Policy

## Reporting a Vulnerability

The Hamekoz organization takes security seriously. We appreciate your efforts to responsibly disclose your findings.

**Please do not report security vulnerabilities through public GitHub issues.**

### How to Report

To report a security vulnerability, please contact us privately via one of the following channels:

- **GitHub Security Advisories**: Use the [Report a vulnerability](https://github.com/hamekoz/.github/security/advisories/new) button on this repository
- **Email**: Send details to the maintainers (preferably via GitHub Security Advisories for traceability)

### What to Include

Please include the following information in your report:

- Description of the vulnerability and its potential impact
- Steps to reproduce the issue (proof of concept if possible)
- Affected versions or commits
- Any suggested fixes or mitigations

### Response Timeline

We aim to respond to security reports as follows:

- **Acknowledgement**: Within 5 business days
- **Initial assessment**: Within 10 business days
- **Resolution plan/updates**: As we investigate, we will keep you informed of progress

### Disclosure Policy

- We will work with you to validate and address the vulnerability
- We ask that you give us reasonable time to fix the issue before public disclosure
- We follow responsible disclosure practices and will credit reporters (with permission) in security advisories/releases

### Security Best Practices

When contributing to Hamekoz projects:

- Never commit secrets, API keys, tokens, or credentials
- Use environment variables or GitHub Secrets for sensitive configuration
- Follow our [AI + security guidelines](docs/ai/AGENTS.md#security)
- Validate and sanitize all external inputs

Thank you for helping keep Hamekoz projects secure.
